# Database Schema (`MongoDB`)

Sanchaya uses MongoDB 7.0 as the shared persistence bridge across `services/backend`, `services/ai-engine`, and `services/analytics-service`. All timestamps are stored in strict UTC ISO-8601 format.

## 1. `users` Collection
Managed by `services/backend`.

```json
{
  "_id": "ObjectId",
  "name": "Ayush Nirmal",
  "email": "ayush@gmail.com",
  "passwordHash": "$2b$12$...",
  "role": "leader | outgoing | incoming",
  "resetPasswordToken": "sha256_hash_optional",
  "resetPasswordExpires": "2026-11-09T15:00:00.000Z",
  "createdAt": "2026-11-09T12:00:00.000Z",
  "updatedAt": "2026-11-09T12:00:00.000Z"
}
```

## 2. `projects` Collection
Tracks workspace metadata, assigned members, and the 7-point Handover Readiness Checklist state.

```json
{
  "_id": "ObjectId",
  "name": "Payment Gateway Microservice",
  "description": "Core checkout and webhook service",
  "githubRepo": "org/payment-service",
  "members": {
    "leaderId": "ObjectId",
    "outgoingIds": ["ObjectId"],
    "incomingIds": ["ObjectId"]
  },
  "readinessChecklist": {
    "sourcesVerified": true,
    "decisionsBackedByEvidence": true,
    "unfinishedTasksAssignedOrUnknown": true,
    "blockersIdentified": true,
    "conflictsDisclosed": true,
    "recipientPermissionsChecked": true,
    "leaderApprovalRecorded": false
  },
  "readinessStatus": "Needs Attention | Ready for Review | Approved for Sharing",
  "approvedBy": "ObjectId | null",
  "approvedAt": "2026-11-09T16:30:00.000Z | null",
  "createdAt": "2026-11-09T12:00:00.000Z",
  "updatedAt": "2026-11-09T16:30:00.000Z"
}
```

## 3. `source_records` Collection
Written by `services/backend` after running `secretScanner.ts`. Read by `services/ai-engine` and `services/analytics-service`.

```json
{
  "_id": "ObjectId",
  "projectId": "ObjectId",
  "source_id": "SRC-GH-014 | SRC-DOC-003 | SRC-TSK-008",
  "source_type": "github_commit | github_pr | github_issue | meeting_note | task_csv",
  "title": "feat(auth): migrate session store to JWT",
  "author": "ayush-nirmal",
  "redacted_content": "Implemented stateless JWT auth. Token key set in [REDACTED_SECRET].",
  "metadata": {
    "fileName": "sprint-4-notes.pdf",
    "commitSha": "a1b2c3d4",
    "filesChanged": ["src/routes/auth.ts"],
    "taskStatus": "in_progress",
    "redactionCount": 1
  },
  "created_at": "2026-10-15T09:20:00.000Z",
  "updated_at": "2026-10-18T14:10:00.000Z",
  "imported_at": "2026-11-09T12:05:00.000Z"
}
```

## 4. `findings` Collection
Written by `services/ai-engine` (`ai_extractor.py` & `evidence_validator.py`) and updated via Leader review in `services/backend`.

```json
{
  "_id": "ObjectId",
  "projectId": "ObjectId",
  "category": "decision | task | blocker | dependency | risk",
  "claim": "Stateless JWT authentication was chosen over Redis sessions to simplify container scaling.",
  "owner": "ayush-nirmal | Unknown",
  "source_id": "SRC-DOC-003",
  "verbatim_excerpt": "decided to use stateless JWTs instead of Redis to avoid extra container state",
  "conflicting_source_id": "SRC-GH-019 | null",
  "verification_status": "Supported | Needs review | Conflicting | Unknown",
  "evidence_origin": "system_verified | self_reported",
  "freshness": {
    "source_updated_at": "2026-10-18T14:10:00.000Z",
    "recheck_recommended": false,
    "reason": null
  },
  "review_status": "pending | approved | rejected",
  "reviewedBy": "ObjectId | null",
  "updatedAt": "2026-11-09T14:00:00.000Z"
}
```

## 5. `gap_questions` Collection
Generated by `services/ai-engine` for `Unknown` or `Conflicting` findings; answered by the Outgoing Member.

```json
{
  "_id": "ObjectId",
  "projectId": "ObjectId",
  "relatedFindingId": "ObjectId",
  "question": "Task TSK-008 (Webhook Retry Queue) has no assigned owner or completion status. What is the current blocker and next step?",
  "status": "pending | answered | approved",
  "answer": "Blocked on Stripe test webhook secret. Next step is wiring dead-letter retry in webhookWorker.ts.",
  "answeredBy": "ObjectId",
  "answeredAt": "2026-11-09T15:10:00.000Z",
  "evidence_badge": "Self-reported"
}
```

## 6. `risk_maps` Collection
Stores deterministic file/module bus-factor metrics computed by `risk_analyzer.py` (e.g., module path, primary contributor percentage, total commits, risk tier: `High` | `Medium` | `Low`).

```json
{
  "_id": "ObjectId",
  "projectId": "ObjectId",
  "modulePath": "src/services/webhook.ts",
  "primaryContributor": "ayush-nirmal",
  "contributionPercentage": 87.5,
  "totalCommits": 48,
  "riskTier": "High",
  "calculatedAt": "2026-11-09T14:00:00.000Z"
}
```

## 7. `handover_history` Collection
Stores immutable snapshots of approved handovers, PDF export timestamps, and incoming member receipt acknowledgements (`acknowledgedBy`, `acknowledgedAt`).

```json
{
  "_id": "ObjectId",
  "projectId": "ObjectId",
  "version": 1,
  "approvedSnapshot": { ... },
  "pdfExportedAt": "2026-11-09T16:45:00.000Z",
  "acknowledgedBy": "ObjectId",
  "acknowledgedAt": "2026-11-09T17:00:00.000Z"
}
```
